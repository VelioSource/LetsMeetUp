# Let's Meet Up! 🌍

**Let's Meet Up!** is a PHP-based social networking platform designed to help people connect with others based on their **nationality, interests, personality, and location**.

The platform is aimed at students, travelers, expats, and anyone looking to meet new people and build social connections in a new environment.

##  Features

*  **User Accounts**

  * Registration and login
  * Session-based authentication
  * User profiles

*  **Find People**

  * Discover users based on nationality
  * Find people with similar interests
  * Filter potential connections based on preferences
  * Approximate distance between users

*  **Friend System**

  * Send friend requests
  * Accept or reject friend requests
  * Manage your friends

*  **Real-Time Chat**

  * Private conversations between users
  * Chat interface for connected friends

*  **Location-Based Matching**

  * Optional location sharing
  * Approximate distance calculation
  * Location is only used when the user opts in

*  **Interests & Preferences**

  * Select personal interests
  * Store user preferences
  * Use preferences to help discover compatible people

*  **Let's Meet Up!+**

  * Planned premium version with additional features

## 🗄️ Database

The application uses a MySQL database hosted through XAMPP.

The database contains information such as:

* User accounts
* User preferences
* Friend relationships
* User interests
* Chat-related data



##  Security

The project uses PHP sessions for authentication and user management.

For a production deployment, additional security measures should be implemented, including:

* Password hashing
* Input validation
* SQL injection protection


##  Project Goals

The main goal of Let's Meet Up! is to make it easier for people to build meaningful social connections when they are away from their usual environment.

Instead of simply matching users randomly, the platform focuses on shared characteristics!
